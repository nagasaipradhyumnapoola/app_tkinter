StudyPilot - Windows desktop application

Download StudyPilot.exe and save it as D:\app\StudyPilot.exe.
Double-click the EXE to start. No separate Python installation is required.
Requires Windows 10/11, 64-bit.

The application uses default Tkinter controls and works offline.
Your personal data is stored next to the executable in data\studypilot.sqlite3.
Keep the data folder when updating the executable.

To explore sample data, run StudyPilot.exe --demo from a terminal or shortcut.
This uses a separate demo.sqlite3 database.

This release is built on a GitHub-hosted Windows runner after backend and Tkinter
workflow checks pass. The source and rebuild workflow are included in this repository.
